# WIN 60 HE 韌體功能說明

這份列出鍵盤韌體本身支援的功能，以及各功能在 aulactl 裡怎麼用（CLI 指令 / GUI 頁面）。
協定細節見 [protocol.md](protocol.md)。標「未實測」的項目，寫法來自官方驅動，還沒在實機上驗證過。

所有設定都存在鍵盤裡（換電腦也有效），只有「電腦端 profile」存在電腦上。

## 觸發（磁軸）

| 功能 | 說明 | 範圍 | 指令 / 頁面 |
|---|---|---|---|
| 觸發點 | 按下多深才算按下。越淺越快，但越容易誤觸 | 0.08–3.40 mm，0.01 mm 一格，每顆鍵各自設定 | `actuation set KEYS --point MM`／觸發 |
| 固定觸發（fixed） | 傳統模式：過觸發點就按下，回到觸發點以上就放開 | — | `--mode fixed` |
| Rapid Trigger（rt） | 過觸發點後，只要往上回彈「靈敏度」這麼多就放開，再往下壓同樣距離又按下，不用回到觸發點。連打快的音遊很有用 | 靈敏度 0.01 mm 起 | `--rt 0.50` |
| RT 分離（rt-split） | 同上，但按下和放開的靈敏度分開設 | — | `--rt 0.30/0.50` |
| 死區（dead band） | 行程最上面和最底部各忽略一段，防止手指輕放或觸底時的抖動誤判 | 上、下各 0–1.00 mm（上+下要小於總行程） | `deadband set KEYS --top --bottom`／觸發 |
| 軸體類型 | 告訴韌體每顆鍵是哪種磁軸，讓行程換算正確。換了軸體類型要重新校準 | 這把鍵盤提供：HM1、HH1、CY1、TC1（TTC Kom） | `switch set KEYS TYPE`／觸發 |
| 重設觸發 | 所有鍵的觸發點 / RT 回出廠值。需要確認，未實測 | — | `reset triggers --yes`／觸發 |

你目前的設定：61 顆鍵都是 RT，觸發點 1.00 mm，靈敏度 0.50 mm，軸體 HM1，死區 0。

## 校準與即時行程

| 功能 | 說明 | 指令 / 頁面 |
|---|---|---|
| 校準（任意鍵） | 開始後把要校準的鍵各按到底再放開，按完結束。換軸、行程讀數怪怪的時候用。會改寫鍵盤裡的校準資料，未實測 | `calibrate --yes`／即時 |
| 即時行程 | 鍵盤把每顆鍵目前壓多深（0.01 mm）傳給電腦，只在鍵有動時才送，約 1.5–5 ms 一筆。只存在 RAM，不改設定 | `travel`、`feed`／即時 |

## 按鍵

| 功能 | 說明 | 指令 / 頁面 |
|---|---|---|
| 按鍵映射（兩層） | Base 層和 Fn 層（按住 Fn 時）每顆鍵可以改成別的鍵、多媒體鍵、滑鼠鍵、組合鍵（如 Ctrl+Shift+Esc）、巨集或高級鍵。Fn 層有 35 顆鍵是韌體固定功能（燈效、Win 鎖等），不能改 | `keymap set KEY ACTION [--layer fn]`／按鍵映射 |
| 巨集 | 10 組。每組是一串按下 / 放開 / 延遲（最多 62 個事件）。播放方式：執行一次、重複 N 次、按一下開始再按一下停止、按住時重複 | `macro set SLOT "..." --mode`／巨集 |
| DKS（動態行程鍵） | 一顆鍵依壓下的不同深度觸發最多 4 個動作：往下過第一段、按到底、從底部回彈、回彈過第一段。例：輕按是 A，按到底再加 Shift | `adv set SLOT dks`／高級鍵 |
| MT（Mod-Tap） | 點一下是一個鍵，按住超過門檻（150–1000 ms）變成另一個鍵。例：點 = Esc，按住 = Ctrl | `adv set SLOT mt HOLD TAP`／高級鍵 |
| TGL（切換鍵） | 點一下讓某個鍵保持按住，再點一下放開 | `adv set SLOT tgl KEY`／高級鍵 |
| 高級鍵上限 | 最多 40 組，要再用按鍵映射綁到實體鍵上（`Adv0..39`） | — |
| SOCD | 兩顆相對方向的鍵（例 A/D）同時按住時怎麼處理，最多 20 組。模式：後按的贏（last）、鍵1 優先、鍵2 優先、後按的不作用（neutral）。可以整體開關，鍵盤上 Fn + 右 Shift 也能切換 | `socd add A D --mode`、`socd on/off`／高級鍵 |
| Win 鎖 | 鍵盤上用 Fn 組合鍵開關。這裡設定開啟時要擋哪些：Win 鍵、Shift+Tab、Alt+F4、Alt+Tab | `winlock`／總覽 |

## Fn 層的「固定」鍵

GUI 按鍵映射頁 Fn 層標「固定」的 35 顆鍵，是韌體內建了 Fn 組合功能、不能改的鍵。鍵盤只回報「哪些鍵固定」，
不回報固定成什麼功能（官方驅動也只顯示 Not Remappable），所以下表來自說明書與實測：

| Fn + | 功能 | 來源 |
|---|---|---|
| 右 Shift | SOCD 開關 | 鍵盤回報（`24 02` 熱鍵 = Fn + 右 Shift），已確認 |
| 左 Win | Win 鎖（鎖住時 Win 鍵恆亮白燈） | 說明書 |
| Esc | `` ` ~ `` | 說明書（部分版本） |
| 1 … 0、-、= | F1 … F12 | 60% 鍵盤慣例，待確認 |
| A / S | 長按 3 秒切 Windows / Mac 模式（閃白燈三次） | 說明書 |
| W | 待確認（可能是 WASD ↔ 方向鍵互換） | — |
| 空白鍵 | 燈光開 / 關 | 說明書（HE 版） |
| 右 Alt | 切換燈效 | 說明書（HE 版） |
| 右 Ctrl | 切換燈色 | 說明書（HE 版） |
| N、O、P、]  | Del、郵件、瀏覽器、計算機 | 說明書（部分版本），待確認 |
| I、J、K、L、[、;、'、M、, | 待確認（推測方向鍵 / 導覽鍵） | — |

非固定的鍵在 Fn 層是空的，可以自己指定功能（`keymap set KEY ACTION --layer fn`）。

## 燈效

| 功能 | 說明 | 指令 / 頁面 |
|---|---|---|
| 燈效模式 | 靜態、呼吸、波浪、霓虹、雷達、按鍵反應、極光、漣漪、閃爍、十字、速度感應、自動漣漪、條紋、煙火，共 14 種，加上自訂 | `light effect MODE`／燈效 |
| 參數 | 亮度 0–4、速度 0–4、前景色 / 背景色、彩虹（全彩）、方向（波浪、雷達、極光、條紋、速度感應才有） | `light brightness/speed/color/direction/rainbow` |
| 自訂逐鍵燈色 | 兩組槽，每顆鍵一個顏色，選一組顯示。注意：寫入燈色時韌體會自動切到自訂模式，aulactl 會在寫完後把原燈效寫回去 | `light custom set KEYS #rrggbb --slot N`、`light slot N`／燈效 |
| 音樂律動 | 跟著電腦播放的聲音閃燈。需要電腦端程式持續送資料，aulactl 只做開關 | `light music on/off`／燈效 |

這把鍵盤沒有側燈。

## 系統

| 功能 | 說明 | 指令 / 頁面 |
|---|---|---|
| 回報率 | 1 / 2 / 4 / 8 kHz（目前 8 kHz）。改了鍵盤會重新啟動（USB 重新連線），aulactl 會自動等它回來 | `pollrate N`／總覽 |
| 全鍵無衝突 | 固定 NKRO，這把鍵盤不能切 6KRO | — |
| 恢復出廠 | 所有設定回出廠值。需要確認，未實測；建議先 `backup` | `reset factory --yes`／總覽 |

## 韌體不支援（同協定的其他型號才有）

- 板載 profile：沒有，aulactl 改用電腦端 profile（`profile save/apply`）
- 搖桿 / 類比手把模式、RS（Rappy Snappy）、RKRT、高精度行程單位、側燈、睡眠計時
- 韌體更新：這個 HID 介面沒有更新指令，官方「更新韌體」只是下載 Windows 程式

## aulactl 額外功能（不在韌體裡）

- 每次第一次寫入前自動備份（`~/.local/share/aulactl/backups/`，保留 20 份）；`backup` / `restore` / `diff`
- 電腦端 profile：`profile save/apply/list/diff NAME`
- 寫入後讀回比對；還原前先完整驗證，有錯就一筆都不寫
- `feed`：給 `aula_keys` 疊加層用的即時按鍵 / 行程資料（[feed.md](feed.md)）
